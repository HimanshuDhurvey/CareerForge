# CareerForge — Client Application

> For complete project documentation, system architecture, API module descriptions, and setup instructions, please refer to the [Root README.md](../README.md).

---

## Tech Stack
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS 4
- **Routing:** React Router 7
- **HTTP Client:** Axios
- **Icons:** Lucide React

## Development
```bash
npm run dev     # Start Vite dev server
npm run build   # Build production bundle
```
