# CareerForge — Backend API Server

> For complete project documentation, system architecture, API module descriptions, AI workflow diagrams, and environment configuration, please refer to the [Root README.md](../README.md).

---

## Tech Stack
- **Runtime:** Node.js v24
- **Framework:** Express.js 5
- **Database:** MongoDB Atlas + Mongoose 9
- **Authentication:** JWT + bcrypt
- **AI SDK:** `@google/generative-ai` (Gemini 1.5 Flash)

## Development
```bash
npm run dev     # Start development server with nodemon
npm start       # Start production server
```
